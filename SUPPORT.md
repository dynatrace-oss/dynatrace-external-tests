# Support

## Support model

This repository is community-supported by the maintainers on a best-effort basis.

## How to get help

Please use [GitHub Issues](https://github.com/dynatrace-oss/dynatrace-external-tests/issues) for:

- Bug reports
- Feature requests
- Questions about the configuration or sample runners

Before opening an issue, search existing issues to avoid duplicates.

If you believe you have found a security vulnerability, do not file a public issue. Follow the instructions in [SECURITY.md](SECURITY.md).

## Commercial support

This repository is not covered by standard Dynatrace commercial support agreements.
